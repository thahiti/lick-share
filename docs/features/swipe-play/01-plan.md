# swipe-play: 카드 재생 버튼으로 여는 전체 화면 넘기기 재생 기획

작성일: 2026-11-10. 모델: fable. 상태: 승인됨.

## 목적

목록 카드에서 상세 페이지로 들어가지 않고 릭을 들을 수 있게 한다.
재생 버튼을 누르면 그 릭이 전체 화면으로 열려 바로 소리가 나고, 위로 넘기면 목록 순서대로 다음 릭이 이어서 재생된다.
한 릭에 머물면 4박을 쉬고 처음부터 반복해, 귀로 골라 보는 탐색이 손을 거의 대지 않고 이어진다.

- `docs/product/SPEC.md` 4절 열람 화면(재생, 음표 탭), 5절 반주와 메트로놈.

- `src/engine/schedule.ts` COUNT_IN_BEATS 4 와 countInEvents(레코딩 예비박).
- `src/community/views/Feed.tsx` FeedList(행, 커서, loadMore, 좋아요 수). 태그 피드, 유저 페이지, 내 릭이 재사용한다.

## 사용자 결정 (2026-11-10)

- 쓰는 장면은 귀로 골라 보는 탐색이다. 연습 장면(클릭 예비박, 템포 조절, 화면 꺼짐 방지)은 이번 범위가 아니다.
- 하단 탭을 늘리지 않는다. 목록 카드의 재생 버튼으로 들어가고, 뒤로 가기로 목록에 돌아온다.
- 넘기면 다음 릭이 즉시 재생된다. 예비박은 한 릭이 계속 반복될 때만 둔다.
- 예비박 4박은 무음이고 화면에 4 3 2 1 카운트다운을 보인다.
- 악보가 한 화면을 넘는 긴 릭은 장 안에서 세로로 스크롤한다. 음표 크기는 유지하고 액션 행은 하단에 고정한다.
- 오버레이 안의 작성자 이름과 태그는 표시만 한다. 유저 페이지와 태그 피드로의 이동은 상세와 목록에서 한다.

## 확정된 사실 (코드 조사)

- 플레이어의 반복(`loop`)은 toStep 에 닿으면 즉시 되감는다. 4박 간격은 어댑터에 옵션을 더해야 한다. 가짜 시계와 가짜 싱크로 테스트할 수 있다.
- `onEnded` 는 자연 종료, 수동 정지, 새 곡 시작 때 모두 불린다. 반복 간격은 UI 타이머가 아니라 플레이어 안에서 자연 종료만 골라 처리해야 한다.
- 오디오 컨텍스트는 전역 pointerdown 에서 resume 된다. 재생 버튼 탭과 스와이프가 모두 제스처라 iOS 의 자동 재생 제한을 통과한다. 간격 뒤 재시작은 같은 세션 안의 스케줄이라 제스처가 필요 없다.
- 목록 행에 blob 이 있어 다음 릭의 디코딩은 즉시 끝난다. 네트워크는 다음 페이지 불러오기에만 든다.
- 카드는 `<button class="c-cardhit">` 하나다. 버튼 안에 버튼을 둘 수 없어 재생 버튼은 카드 안에서 그 버튼의 형제 요소로 둔다.
- 라우트가 바뀌면 Feed 가 다시 마운트돼 첫 페이지부터 다시 받고 스크롤 위치를 잃는다. 상세로 갔다 올 때 지금도 그렇다.
- 데스크톱(1024px 이상) 목록 열 폭은 692px, 폰 카드의 악보 폭은 340px 다. 악보는 폭과 밀도로 줄을 나눈다(2026-11-10 적용).

## 구조 (판단)

- 오버레이.
  새 라우트가 아니라 FeedList 안의 전체 화면 오버레이로 연다.
  history 에 항목 하나를 넣어 브라우저 뒤로 가기가 오버레이를 닫는다. 넘기는 동안 URL 은 바꾸지 않는다.
  목록은 뒤에 그대로 있어 닫으면 스크롤 위치가 남고 다시 받지 않는다.
  버린 대안은 `/play/:id` 라우트다. 딥링크는 되지만 목록 재마운트 문제를 그대로 안는다. 공유는 기존 `/s/:id` 가 맡는다.
- 데이터.
  오버레이는 목록이 이미 받은 행과 loadMore 를 그대로 쓴다. 순서가 목록과 같고 중복 조회가 없다.
  뒤에서 두 번째 릭에 이르면 다음 페이지를 미리 받는다.
- 넘기기.
  세로 scroll-snap 컨테이너. 스와이프, 휠, 방향키가 브라우저 기본 동작으로 모두 된다.
  멈춘 장을 IntersectionObserver 로 정하고 그때 재생을 바꾼다. 빠르게 지나간 장은 재생하지 않는다.
- 반복 간격.
  플레이어 play 의 loop 를 간격(박)을 받는 형태로 넓힌다.
  간격 동안 onTick 대신 간격 진행을 알리는 콜백을 둬 화면이 4 3 2 1 을 그린다. API 는 명세 단계에서 정한다.
- 데스크톱.
  같은 오버레이를 가운데 680px 열로 보이고 Esc 로 닫는다. 넘기기는 휠과 방향키.
- 악보 탭.
  오버레이에서 악보 탭은 멈춤과 재개다. 상세의 "음표 탭 = 그 음부터 재생" 은 오버레이에 두지 않는다.
- 긴 릭.
  장의 내용이 뷰포트보다 길면 장 안에서 세로 스크롤한다. 안쪽 스크롤이 끝에 닿으면 바깥 스냅이 다음 장으로 넘긴다.
  액션 행은 장 하단에 고정해 스크롤과 무관하게 닿는다. 버린 대안은 축소(음표 크기 원칙 위반)와 고정 높이 자르기(플레이헤드 추적 작업).
- 나가기.
  오버레이를 떠나는 길은 닫기 버튼, 뒤로 가기, 복제 편집 셋뿐이다.
  복제 편집은 재생을 멈추고 오버레이가 넣은 history 항목을 replaceState 로 걷어낸 뒤 `/edit#blob` 으로 간다. 편집의 Back 이 목록으로 바로 돌아오게 하기 위해서다.
- 소리와 상태.
  재생 옵션은 상세와 같다(멜로디, 반주, 메트로놈 모두 곡 데이터대로).
  멈췄다 재개한 뒤에도 끝에 닿으면 처음(0 스텝)부터 반복한다.
  오버레이에서 누른 좋아요는 목록 카드의 좋아요 수에도 반영한다.
  힌트 노출 여부는 이 기기의 localStorage 에 둔다. 읽기 실패는 힌트를 다시 보이는 것으로 처리한다.
  검색 결과의 카드는 재생 버튼을 받지 않는다(다음 기능).

## 종료 시나리오

폰 폭(390px)에서 확인한다. S12 만 데스크톱 폭(1280px)에서 확인한다. S15 는 8마디 릭을 편집기로 만들어 게시한 뒤 확인한다.

S1. Latest 의 카드에 재생 버튼이 보인다.
    누르면 전체 화면이 열리고 그 릭이 바로 재생된다(플레이헤드가 움직이고 반주가 곡 설정대로 난다).
    화면에 악보, 제목, 작성자, 태그, 좋아요 수와 버튼, 공유, 복제 편집이 보인다.
    카드 본문을 누르면 지금처럼 상세로 간다.
S2. 악보를 탭하면 멈추고(플레이헤드 유지) 다시 탭하면 그 자리부터 이어 재생된다.
S3. 재생 중 위로 넘기면 목록의 다음 릭이 화면을 채우고 즉시 처음부터 재생된다. 앞 릭 소리는 즉시 멈춘다.
S4. 멈춘 상태에서 넘기면 다음 릭은 멈춘 채 보이고 탭해야 재생된다.
S5. 아래로 넘기면 직전 릭으로 돌아간다. 재생 중이었다면 그 릭이 처음부터 재생된다.
S6. 한 릭이 끝나면 소리 없이 화면에 4 3 2 1 이 박 간격으로 보이고, 4박 뒤 처음부터 다시 재생된다. 넘기거나 멈추기 전까지 반복한다.
S7. 카운트다운 중 넘기면 카운트다운이 사라지고 다음 릭이 즉시 재생된다. 카운트다운 중 탭하면 멈춘다.
S8. 빠르게 두 장을 연달아 넘기면 중간 장은 재생되지 않고 멈춘 장만 재생된다.
S9. 목록 끝에서 두 번째 릭에 이르면 다음 페이지가 미리 불려 끊기지 않는다. 마지막 릭에서는 더 넘어가지 않는다.
S10. 브라우저 뒤로 가기 또는 화면의 닫기 버튼을 누르면 소리가 멈추고 보던 목록이 같은 스크롤 위치로 보인다. 목록을 다시 받지 않는다.
S11. 좋아요는 상세와 같다. 비로그인은 "Sign in to like" 토스트, 로그인은 즉시 반영, 유사 릭은 원본에 귀속.
     공유는 `/s/:id` 링크(공유 시트 또는 복사). 복제 편집은 소리를 멈추고 `/edit#blob` 으로 간다.
S12. 데스크톱 1280px 에서 같은 버튼으로 열면 가운데 열로 보이고 휠과 방향키로 넘어가며 Esc 로 닫힌다.
S13. 태그 피드(`/tag/:name`)와 유저 페이지의 카드에서도 같은 버튼으로 열리고 그 목록 순서로 넘어간다.
S14. 처음 열 때 "Swipe up for the next lick" 힌트가 보이고 한 번 넘기면 사라진다. 그 뒤로는 이 기기에서 보이지 않는다.
S15. 8마디 릭(사용자가 만든 긴 릭)을 열면 악보가 장 안에서 세로로 스크롤되고 액션 행은 하단에 남는다.
     스크롤이 끝에 닿은 뒤 한 번 더 밀면 다음 릭으로 넘어간다. 음표 크기는 다른 릭과 같다.
S16. 오버레이의 작성자 이름과 태그는 눌러도 이동하지 않는다. 복제 편집으로 나간 뒤 편집의 Back 을 누르면 목록이 바로 보인다(오버레이가 끼어들지 않는다).

## 범위

포함:
- 카드 재생 버튼(Latest, 태그 피드, 유저 페이지, 내 릭)
- 전체 화면 오버레이 페이저, 즉시 재생, 멈춤과 재개, 4박 무음 반복과 카운트다운
- 좋아요, 공유, 복제 편집
- 데스크톱 가운데 열 변형
- 처음 한 번 힌트

제외 (다음 기능 또는 다음 버전):
- 템포 조절, 클릭 예비박, 메트로놈 토글. 연습 장면이며 상세 페이지에 남는다.
- N회 반복 뒤 자동으로 다음 릭. 탐색은 사용자가 넘긴다.
- 검색 결과(SearchResults)의 카드. 목록 컴포넌트가 달라 다음 기능.
- 랭킹 화면과 Top Licks 위젯. 목록이 아니다.
- 화면 꺼짐 방지(Wake Lock), 백그라운드 재생.
- 딥링크 `/play/:id`.
- 오버레이 안 작성자와 태그 링크(태그로 이어 듣기). 다음 기능 후보.
