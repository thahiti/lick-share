# swipe-play: 카드 재생 버튼으로 여는 전체 화면 넘기기 재생 디자인

작성일: 2026-11-10. 모델: fable. 상태: 승인됨.
시안: `docs/features/swipe-play/mockup.html` (Artifact 링크: https://claude.ai/artifact/At1q6uiwCv52J72UpNFqnx)

시안의 악보는 실제 Score 렌더러 출력(2026-11-10 적응형 줄 나누기 적용본)이다.
시안 자체가 세로 스냅 페이저라 휴대폰에서 위로 넘기면 상태가 순서대로 나온다. 노란 라벨은 시안 설명이고 실제 화면에는 없다.

## 상호작용

- 터치: 카드 재생 버튼 탭이 오버레이를 열고 재생한다. 오버레이에서 위로 스와이프는 다음, 아래로는 이전. 악보 탭은 멈춤과 재개. 닫기 버튼 탭은 닫기.
- 마우스(데스크톱): 휠로 넘기기, 악보 클릭으로 멈춤과 재개, 닫기 버튼 또는 스크림 클릭으로 닫기.
- 키보드(데스크톱): 위 아래 방향키로 넘기기, Space 로 멈춤과 재개, Esc 로 닫기. 오버레이가 열리면 포커스를 닫기 버튼에 둔다.
- 넘김 판정: 스냅이 멈춘 장만 재생한다. 두 장을 빠르게 넘기면 중간 장은 소리가 나지 않는다.
- 카운트다운: 박 간격으로 4, 3, 2, 1. 숫자는 남은 박, 점은 지난 박. 소리는 없다.
- 오류 표시: 목록 다음 페이지 불러오기 실패는 마지막 장 아래에 "Couldn't load more" 와 Retry(기존 목록 문구와 같다). 좋아요 실패는 "Like failed" 토스트와 되돌림(상세와 같다).
- 힌트: 처음 열 때만. 한 번 넘기면 사라지고 localStorage 에 기록한다.

## 레이아웃 티어

- 휴대폰(640px 미만): 오버레이가 화면을 다 채운다. 악보 폭은 358px(16px 거터). 액션 행은 safe-area 아래 여백을 더한다.
- 태블릿(640~1023px): 휴대폰과 같은 전체 화면. 악보 폭이 넓어져 줄당 마디가 는다.
- 데스크톱(1024px 이상): 스크림 위 가운데 680px 열, 최대 높이 92dvh, radius 12, 팝오버 그림자. 목록과 사이드바는 스크림 뒤에 그대로 있다.
- 색과 간격은 `src/styles/tokens.css` 의 토큰만 쓴다. 새 토큰은 스크림(`rgba(17,17,17,0.55)`) 하나다.

## 데이터와 API 변경

- 테이블(`supabase/schema.sql`): 없음.
- 질의(`src/community/api/`): 없음. 목록이 받은 행(`LickRow`, blob 포함)과 `fetchFeedPage` 커서를 그대로 쓴다. 좋아요는 `addLike`, `removeLike`, `fetchLikeCounts` 그대로.
- 플레이어(`src/adapters/player.ts`): 반복 간격 옵션과 간격 진행 콜백. 명세 단계에서 API 를 정한다.

## 기존 화면과 다르게 한 점

- 전체 화면 오버레이는 이 앱에 처음 생기는 표면이다. 상세의 악보 프레임(1px ink, radius 12), 액션 행 순서(Duplicate and edit, Like, Share), 토스트는 그대로 가져왔다.
- 카드 위의 원형 재생 버튼은 새 요소다. 44px 은 터치 최소 크기이고 색은 primary 하나뿐이라 화면에 primary 가 둘(카드 버튼, 탭바 Create)이 된다. 목록에서는 재생이 가장 중요한 행동이라 허용한다.
- 카운트다운 숫자 72px 은 이 앱에서 가장 큰 글자다. 반복 사이의 4박이 비어 있지 않음을 한눈에 알리기 위해서다.
